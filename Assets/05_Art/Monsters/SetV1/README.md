## 방향과 시점

위에서 내려다본 느낌이 나면서 얼굴과 장비가 보이는 캐릭터 시안입니다. 타워와 같은 게임에 쓰기 위한 스타일을 맞췄으며 타워의 수직 탑다운 투영과 완전히 동일한 카메라 투영은 아닙니다. 모두 오른쪽을 향하고, 왼쪽 이동에는 좌우 반전을 사용할 수 있습니다. 위아래 이동의 별도 방향 이미지는 없습니다.

## Unity에서 이동 시트 나누기

모든 PNG는 1254×1254이고, 시트는 2열×2행입니다. 각 프레임은 627×627입니다.

1. 이동 시트를 선택하고 Texture Type을 Sprite (2D and UI), Sprite Mode를 Multiple로 설정합니다.
2. Sprite Editor에서 2열×2행으로 나누거나 Cell Size 627×627로 나눕니다.
3. 프레임 순서는 위 왼쪽 → 위 오른쪽 → 아래 왼쪽 → 아래 오른쪽입니다.
4. 공통 Pixels Per Unit으로 가져온 뒤 각 종류의 크기는 오브젝트 스케일로 조절합니다.
5. 생성 이미지의 중심 차이를 줄이기 위해 프레임별 Custom Pivot 값을 조정합니다.

monster-animation-layout.json의 pivots는 각 프레임 왼쪽 위를 원점으로 한 정규화 좌표입니다. Unity Custom Pivot은 X를 그대로 사용하고 Y를 1-Y로 바꿉니다. 이 값은 브라우저 미리보기에서 육안으로 맞춘 시작값이며 Unity에서 실제 적용해 검증한 값은 아닙니다.

미리보기의 일반형 8 FPS, 고속형 12 FPS, 중장형 6 FPS는 제작 확인용 제안값입니다. 이동 속도나 전투 수치를 확정한 것은 아닙니다.

## 미리보기와 확인

preview.html을 브라우저에서 열면 3종 이동을 재생할 수 있습니다. 재생·정지, 한 프레임 넘기기, 좌우 반전, 속도 변경을 넣었습니다.
PNG 원본을 CSS로 표시하며 이미지 파일 자체를 프로그램으로 재가공하지 않았습니다.

- 기본 이미지와 이동 시트 6개를 확인했습니다.
- 각 시트에서 네 포즈의 장비가 유지되고, 칸 경계에서 잘리는 문제를 확인·수정했습니다.
- 일반형 최종 시트의 중앙 가로·세로 경계에서 알파 최대값 1을 확인했습니다. 실질적으로 투명한 여백입니다.
- 고속형·중장형은 각 칸의 실루엣 바깥에 여백이 있는 것을 표본 픽셀로 확인했습니다.
- 브라우저에서 이미지 로드 실패 없이 3종 재생과 좌우 반전을 확인했습니다.
- AI 생성 프레임 간 팔다리·외곽선의 미세한 형태 차이는 남아 있으므로 최종 게임 크기에서 확인이 필요합니다.
- Unity 스프라이트 분할·피벗 설정·Animation Clip·Animator 연결·실제 이동 테스트는 아직 수행하지 않았습니다.
