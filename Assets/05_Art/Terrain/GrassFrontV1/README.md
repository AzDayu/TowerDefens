# 초원과 흙길의 방어 전선 · 첫 맵 시안

2026-10-14 · 내장 image_gen 사용 · 신규 배경 PNG 2개 · 각 1672×941, 24비트 RGB.
테마는 사용자가 선택한 초원과 흙길입니다. 이동·설치 방식에 대한 답은 아직 없어, 고정 경로와 설치 후보 6곳으로 만든 시안입니다. 이 규칙을 사용자 확정 사항으로 취급하지 않습니다.

## 파일

- grass-ground-v1.png: 길 없이 비워 둔 초원 바탕.
- grass-defense-path-v1.png: 하나의 연속된 흙길이 있는 맵.
- map-layout.json: 이동 경로, 설치 후보 6곳, 권장 월드 크기와 좌표 변환 기준.
- preview.html: 기존 타워·몬스터를 얹어 배치를 확인하는 로컬 브라우저 미리보기.
- support/: 미리보기에 사용하는 기존 타워 레이어 7개와 몬스터 이동 시트 3개. 이번에 새로 만든 이미지가 아닙니다.
- generation-prompts.md: 두 배경의 생성·편집 프롬프트.
- map-preview.jpg: 최종 배치 확인 화면.

## 배치 제안

적은 왼쪽 위에서 들어와 윗길을 오른쪽으로 이동하고, 오른쪽 굽이에서 가운데 길로 내려갑니다. 가운데 길을 왼쪽으로 이동한 뒤 왼쪽 굽이를 돌아 아랫길로 내려오고, 오른쪽으로 빠져나갑니다.

길 사이의 초원에 2줄×3개, 총 6개의 설치 후보를 배치했습니다. 타워와 설치 표시, 몬스터는 배경 PNG에 그려져 있지 않습니다. 배경에는 초원·흙길·가장자리 장식만 있습니다. 기지 건물은 아직 제작하지 않았습니다.

미리보기의 타워 종류·레벨과 몬스터 수·속도는 가독성 확인용 예시입니다. 전투나 밸런스, 골드·설치 규칙을 확정한 것은 아닙니다.

## Unity 적용 기준

권장 시작 월드 크기는 가로 20, 세로 약 11.256 유닛입니다. 배경 이미지를 이 크기로 표시하려면 Pixels Per Unit을 83.6으로 설정할 수 있습니다. 카메라의 Orthographic Size 시작값은 약 5.628입니다. 실제 카메라 종횡비와 UI 영역에 맞춰 최종 조정합니다.

map-layout.json의 정규화 좌표는 왼쪽 위가 (0,0), 오른쪽 아래가 (1,1)입니다.
월드 변환 기준은 X=(u-0.5)×20, Y=(0.5-v)×11.256입니다. Unity 월드 좌표도 JSON에 함께 기록했습니다.

길의 중심은 생성된 이미지에서 육안으로 맞췄고, 굽이에는 여러 점을 두었습니다. JSON은 좌표 자료이며 Unity에서 자동으로 경로·설치 오브젝트를 생성하는 코드가 아닙니다.
